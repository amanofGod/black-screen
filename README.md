# 洛克虚拟黑屏

Windows 本地工具。在游戏保持前台时，用黑色覆盖层遮住所有显示器，并隐藏系统鼠标指针。覆盖层不抢焦点，鼠标点击和用户已有的连点可继续传给下方游戏。

当前版本：v5。使用 Python 标准库和 Windows 自带接口，无需安装第三方 Python 包。

## 启动与操作

需要 Windows 10/11 和可在命令行使用的 64 位 Python 3。双击 black_screen.cmd 启动。

| 按键 | 效果 |
| --- | --- |
| F10 | 黑屏／恢复画面 |
| F12 | 恢复画面和鼠标，保留程序待命 |
| Ctrl + Alt + F12 | 完全退出程序 |

F12 恢复后可直接再按 F10，无需重启工具。重复双击启动文件会复用已有实例并刷新监听，不再报“已经运行”。

游戏使用窗口或无边框模式并保持前台。如果游戏以管理员权限运行，工具也应使用相同权限。回到其他工作前，先停止原有连点。

完整说明与验证记录见 [BLACK_SCREEN.md](BLACK_SCREEN.md)。

## 功能与范围

- 全屏黑色覆盖，鼠标穿透，不抢游戏焦点。
- 临时隐藏系统指针；恢复、退出和异常清理时还原。
- 游戏／前台线程切换后刷新按键监听，定期更新可能失效的回调。
- 恢复画面后缩小隐藏绘制表面并释放指针接口初始化资源。
- 单实例运行，不保存键盘日志，不修改游戏文件。

工具负责遮住画面，连点仍由用户自己的设备或软件完成。这不是关闭显示器背光或锁定电脑，也没有解决游戏在后台时接收输入的问题。

## 验证与诊断

验证前按 Ctrl + Alt + F12 完全退出工具。测试会短暂黑屏并自动恢复。

    python -B black_screen.py --verify
    python -B black_screen.py --status
    python -B black_screen.py --restore-cursor

已验证重复黑屏／恢复、F12 保留实例、完全退出、监听修复、单实例复用、指针恢复、覆盖置顶及焦点保持。在《洛克王国：世界》前台的模拟按键测试也已通过；其他游戏及长期使用的效果需实际验证。

反复开关后的工作集约 17 MB，私有提交量约 9.5 MB。尚未证明物理内存明显降低，详细测量条件见 BLACK_SCREEN.md。
